# Qeoresearch Project #9: Micrograd Web Engine

Minimalistyczna implementacja silnika automatycznego różniczkowania (Autograd) w czystym Vanilla JavaScript, stworzona w ramach dziewiątego projektu badawczego dla **Qeoresearch**.

Repozytorium demonstruje pełny cykl życia grafu obliczeniowego (Forward & Backward Pass) bezpośrednio w przeglądarce użytkownika bez zewnętrznych zależności (No-Frameworks, No-Slop).

## Struktura projektu
- `index.html` - Główny interfejs demonstracyjny z grafem obliczeniowym live.
- `login.html` / `dashboard.html` - System autoryzacji inżyniera.
- `script.js` - Rdzeń silnika (Klasa `Value`) oraz mechanika routingu i stanów.
- `style.css` - Minimalistyczny, techniczny arkusz stylów.

## Jak uruchomić lokalnie
1. Sklonuj repozytorium: `git clone https://github.com/hank-devz/qeoresearch-p9.git`
2. Otwórz plik `index.html` w dowolnej przeglądarce internetowej.
